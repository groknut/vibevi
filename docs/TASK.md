
# Задачи, которые необходимо выполнить
1. Создать viewer для максимального количества файлов
2. Список необходимых пакетов для установки на чистой ubuntu
3. Функционал

    - Поддерживается сортировка файлов по дате, имени и типу
    - Чем больше типов файлов поддерживается, тем лучше: txt, doc/docx, jpeg, png, avi, etc....
    - Просмотр не должен использовать сторонние приложения, все должно быть решено программно
4. Подготовить документацию Doxygen
